# Inglés Nivel 1 — mapa de 100 clases editoriales

Estado: mapa de migración. F0 se conserva como prerrequisito separado. Este nivel corresponde a A1 y no usa tutor IA como componente obligatorio.

Leyenda de origen: `C` conservar, `D` dividir una unidad actual, `R` reescribir/adaptar, `N` crear.

Cada bloque sigue cinco momentos: entrada, patrón, comprensión, producción y transferencia/evaluación. Los nombres entre paréntesis remiten a unidades actuales cuando existe correspondencia.

## Exclusiones del Nivel 1

El PDF original adelanta contenidos que no deben forzarse en A1: `past be`, pasado simple completo, `going to`, `will`, problemas complejos de viaje/trabajo y actividades multimedia abiertas. Se reubicarán desde el Nivel 2 según prerrequisitos y carga cognitiva.

## Condición para convertir este mapa en contenido

Cada clase debe recibir IDs estables, vocabulario real, ejemplos, errores frecuentes, pasos de enseñanza, práctica, situación, evaluación y variantes de repaso. Ningún título de este documento cuenta como clase publicada hasta pasar la biblioteca editorial, el validador semántico y la revisión pedagógica.

# Portugués legado retirado del runtime

Fecha: 2026-10-03.

Este directorio conserva, solo para trazabilidad y posible consulta histórica, el contenido portugués anterior al nuevo diseño pedagógico:

- `assets-contenido-pt/`: paquetes que estaban activos en `assets/contenido/pt/` (`nivel-0.json`, `nivel-1.json`, `nivel-2.json` y la ruta inicial `f0` + `a1-1`);
- `content/pt/`: las 48 unidades fuente del pipeline antiguo;
- `semillas/`: las tres semillas antiguas de niveles 0–2.

No es fuente de verdad, no debe volver a empaquetarse y no se usa para planificar el nuevo curso. El portugués nuevo comienza desde un Nivel 0 propio de pt-BR, continúa con Fundamentos nuevos y después con N1–N10 de 50 clases cada uno.

La carpeta `content/pt/` original puede seguir existiendo vacía debido a directorios virtuales de la herramienta (`.git`, `.codex`, `.agents`); no contiene unidades educativas activas.

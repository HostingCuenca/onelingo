## Ejemplos antes → después

1. tyre / licence / litre / petrol (s12, s13, s14): `tyre` → `tire`; `licence` → `license` (es «licencia de manejo»); `litre` → `gallon`; `petrol` → `gas`.
2. s13 intermedio: «service station» / «forecourt» / «top up» → `rest stop`, `gas cap`, `squeegee`; «Do you have an air pump?» → «Do you have air for the tires?».
3. s11 avanzado: `motorway` → `freeway`; `cut it fine` → `cut it close`; `junction` → `intersection`.
4. s12 intermedio: «basic cover … full insurance» → «basic coverage … full coverage»; `excess` → `deductible`.
5. s15 intermedio: `sick note` → `doctor's note` (es «justificante médico»); «Soy alérgico a la penicilina» → «Tengo alergia a la penicilina».
6. s16: `tablet` → `pill`; `expiry date` → `expiration date`; `leaflet` → `package insert`; «I have a prescription to collect» → «I have a prescription to pick up».
7. s18: `cash machine` → `ATM`; `direct debit` → `automatic payment`; `standing order` → `recurring transfer`; `fixed-term deposit` → `certificate of deposit`.
8. s19: `checkout assistant` → `cashier`; `queue` → `line`; «at the till» → «at the register»; `voucher` → `promo code`; `loyalty points` → `rewards points`.
9. s17: «I'm afraid I've been putting off coming for a while.» → «I'm embarrassed to say it's been a few years since my last visit.»; `anaesthetic` → `local anesthetic`; `instalments` → `installments`.
10. Naturalidad: s15 «My throat has hurt since yesterday.» → «I've had a sore throat since yesterday.»; s11 «Could you drop off my friend at the station?» → «Just drop off my friend first, then me.».

## Notas
- Temas sensibles (médico, farmacia, dentista, banco): solo lenguaje; sin consejos profesionales.
- Se sustituyeron entradas de vocabulario que eran oraciones («Could you stop here?», «Is there an extra charge?», «Could I have a receipt?») por colocaciones.
- Se mantiene el trato de «usted» con desconocidos en servicios (taxista, farmacéutico, cajero), natural en español de América.

# Revisión lote 4 (situaciones 31–40, alemán)

Validador: `validar_situaciones.py` → 0 errores. Estructura, ids e intenciones coinciden con el contenido inglés aprobado; los títulos `en` heredados del lote portugués son fieles a las frases alemanas (solo se ajustaron s33-o2 y s37-o1).

## Cambios por tipo
- **Alemán (naturalidad/gramática):** colocaciones y orden más naturales (abbuchen, Betrieb eingestellt, Verspätung haben, Weg beschrieben, Kündigungsfrist einräumen, an seine Grenzen gehen, Terminkonflikte, Arbeitszeiten, Snackbar, sich fortbewegen/umsteigen, sich orientieren).
- **Falsos amigos / errores de sentido:** Entschuldigungen → Ausreden (excuses); Flexpreis era «tarifa de hora punta» (en realidad tarifa flexible, reembolsable); ejemplo de «bereit sein» pasó de «listo» a «dispuesto».
- **Español latino neutro:** hora punta → hora pico, atasco → embotellamiento, taquilla → ventanilla de boletos, abono → pase mensual, recreo → descanso, atrapante → emocionante, «sirve la pena» → «vale la pena», subjuntivo en s39-a2.
- **Inglés americano:** cancelled → canceled, work stoppage → strike, traffic gridlock → traffic jam, ticket kiosk → ticket machine, cinema → theater, rip current → current.
- **Coherencia es/en/de:** s34-i-f4 (Abend → Nachmittag para igualar «tarde»), s33-o2 y s37-o1 (título), s39 Stadtführer = guía turístico.

## Ejemplos antes → después
1. «Der Verkehr wurde mitten auf meiner Strecke eingestellt» → «Der Betrieb wurde …»
2. «Ich möchte keine Entschuldigungen suchen» → «keine Ausreden suchen»
3. Flexpreis: «Am Freitag gilt meist der Flexpreis» → «Mit dem Flexpreis darf ich jeden Zug am Reisetag nehmen» (+ es/en corregidos)
4. «Wegen des Streiks: Könnten Sie …» → «Wegen des Streiks möchte ich fragen, ob Sie … umbuchen könnten, ohne dass ich den Aufpreis zahlen muss»
5. «mir eine Kündigung mit einem Monat Frist erlauben» → «mir eine Kündigungsfrist von einem Monat einräumen»
6. «den falschen Weg gewiesen» → «den Weg falsch beschrieben»
7. «Hätten Sie vielleicht eine Auskunft, wann der nächste fährt?» → «Könnten Sie mir vielleicht sagen, wann der nächste fährt?»
8. «Ich werde pünktlich bereit sein» (bereit sein = dispuesto) → «Ich bin gern bereit, meine Argumente zu erläutern»
9. es «esta sirve la pena» → «esta vale la pena»; «Confirmar una dirección» → «Confirmar el camino»

# Guías de pronunciación B1–B4 (convención Calibración punto 6)

Solo se tocaron grafías de guía y frases que las describen. Texto francés, respuestas, opciones, tokens, audio e ids intactos. El lado en (“…”) ya usaba “zh” de forma consistente; no hubo cambios en inglés.

## B1 (12 apariciones)
- «yé» -> «shé» (6): letra G, apoyo, pista, feedback, errorFrecuente.
- «yi» -> «shi» (4): letra J.
- «yö mapel» -> «shö mapel» (1); «yö süi» -> «shö süi» (1).

## B2 (10 apariciones)
- «lé yan» -> «lé shan» (les gens); «yabit» -> «shabit» (2, j'habite); «yem» -> «shem» (3, j'aime).
- «medsán» -> «medsén»; «magazán» -> «magazén» (nasal in).
- «un-nom» -> «en-nom»; «un-nopital» -> «en-nopital» (nasal un).
- Se mantienen «fiy», «travay(é)» (ill = y real), «parlén» (lectura errónea intencionada en erroresFrecuentes).

## B3 (7 apariciones)
- c11: «an» nasal -> «en» nasal (un); texto «parecido a «an»» -> «en»; «an livr» -> «en livr».
- «sank» nasal -> «senk» nasal (cinq).
- «yé» -> «shé» (j'ai, c13).
- «an-nan» -> «en-nan» (un an); «shian» -> «shién» (chien).

## B4 (4 apariciones)
- «yö nö süi pa» -> «shö nö süi pa»; «oyurdüí» -> «oshurdüí» (aujourd'hui).
- «un shién» -> «en shién»; «vent-é-un» -> «vent-é-en».

## Ambiguos, sin tocar
- Inglés: nasal un se aproxima con “uh(n)” / “uhn” (B2 “uh-nom”, B3 “uh(n)”, B4 “uhn shyan”, “vahn-tay-uhn”) en vez de “a(n)”; es fonéticamente correcto y consistente, solo difiere de la formulación del encargo.
- B3 inglés “sank” (cinq) y “kanz” (quinze): ya son “a”, coherentes con “van”.
- «ill» = «y» (fille, travailler, crayon, cahier) y «il y a» = «ilia» son correctos.

## Revisión punto por punto

1. **Francés de Francia.** Hora oficial («quatorze heures trente-cinq», «dix-sept heures cinq», «vingt et une heures quarante», «vingt heures quarante-cinq», sin «et quart» ni «moins le quart»); dans (futuro desde ahora) frente a pendant (duración) y en (lo que dura una acción); il dit que / il demande si, s’il / s’ils, sin cambio de tiempo ni de pronombre erróneo; je vois / nous voyons, je crois / nous croyons, ils voient / croient; «sont priés de» solo reconocimiento; j’ouvre / tu ouvres / il ouvre / nous ouvrons, j’offre…; «pour trois nuits»; lequel / laquelle / lesquels / lesquelles concordando con el sustantivo; qu’est-ce qui s’est passé ? frente a qu’est-ce que vous cherchez ?; comme al inicio, parce que en medio; donc / alors / c’est pourquoi / pourtant. Vocabulario SNCF correcto: un aller simple, un aller-retour, la voie, le quai, le guichet, le contrôleur; no aparece composter. Vocabulario de hotel y aeropuerto auténtico (libérer la chambre, pièce d’identité, carte d’embarquement, objets trouvés).
2. **Explicaciones es / en.** Cortas, con ejemplos y las trampas comunes (en vs dans, quatorze trente-cinq sin heures, il dit sin que, Qu’est-ce que s’est passé, Comme… donc). es con tú y léxico neutro (boleto, maleta, equipaje, taquilla, andén, mochila, cinta de equipajes); en americano (round-trip ticket, track, platform, boarding pass, baggage carousel, lost and found, youth hostel, sweater).
3. **Respuesta única y `aceptadas`.** Revisados los 5 `ordenar` y los 5 `escribir` puntuables: c31 g3 / e6, c33 e6, c34 e6 y c35 i4 / e6 con todos los órdenes y variantes naturales (donc / alors / c’est pourquoi / comme en la consecuencia). Cada distractor falla por una sola razón (dans / pendant / en, que / si / qui, laquelle / lequel / lesquelles, qu’est-ce qui / que, donc / pourtant / comme).
4. **Pistas y relacionar.** Las pistas ayudan a su ítem (género y número del sustantivo, sujeto o complemento tras qu’est-ce, consecuencia vs. oposición, «sigue contando después de las 12»). Las glosas de los relacionar son claramente distintas (taquilla / andén / salida / llegada; ida / ida y vuelta / transbordo / revisor; vuelo / embarque / tarjeta / control; individual / doble / recepción / pasaporte; maleta / mochila / asa / etiqueta; así que / sin embargo / porque / como; itinerario / paisaje / albergue / inolvidable).
5. **Guías de sonido (regla 6).** j y g suave = «sh» (en: «zh»), nasales in / un = «en», an / en = «an», on = «on» (en: la n no suena), oi = «ua», ü y ö definidas en c31 y recordadas donde aparecen, eu / e = «ö», ch = «sh», gn = «ñ», consonantes finales (la t de «départ» y «passeport», la s de «alors», la c de «donc» sí suena), liaison de «heures» («ka-tor-zör»).
6. **Hablantes y situaciones.** Una sola respuesta correcta por pregunta de comprensión; tuteo Ana–Lucas–Hugo–Léa y vous con empleados, recepcionista y agente.
